Projects

ML Alpha Ranking Portfolio The Finance Association (TFA) - EPFL

  • Proposed and developed a quantitative investment strategy, “Alpha Ranking Portfolio,” aimed at modeling the relative ranking of assets based on cross-sectional features rather than predicting absolute returns. The project uses the Open Asset Pricing dataset (Zimmermann, 2022) and trains multiple machine learning models (XGBoost, LightGBM, ensembles) with ranking-based loss functions (pairwise and listwise). The models are evaluated out-of-sample using ranking metrics (NDCG, Hit@K) as well as economic validation based on return spreads between top and bottom deciles. Based on these signals, simple long-only portfolio strategies (equal-weighted and market-cap weighted) are implemented and compared against the S&P 500 benchmark in an out-of-sample setting. The project is ongoing, with planned improvements in data quality, feature engineering, model robustness, and portfolio construction methods.
